Plex Backup

Plex Backup is a personal backup tool operated by GitHub user wess24m. It uses rclone to store encrypted backup archives in the operator's own Google Drive account and support backup checks, retention, and recovery.

This application is for the operator's personal use. It does not offer public registration or a backup service for other people.

Google Drive authorization is used for backup operations. The application requests full Google Drive access; that permission is broader than the backup folders it uses.
