Plex Backup Privacy Policy

Effective when this page is published.

Purpose and access

Plex Backup uses Google Drive to store and manage the operator's personal backups. It requests the full Google Drive permission, which technically permits access to files throughout the authorized account. Its intended use is uploading, listing, checking, retrieving, and deleting backup data in its backup folders.

Data handled

The application handles personal backup archives and the file information needed to manage those backups, such as names, sizes, and timestamps. Backup contents are encrypted on the operator's system before being uploaded to the operator's Google Drive account.

OAuth credentials are retained in access-restricted configuration on the operator's own system to allow scheduled backups. They are not included in this public website.

Use and disclosure

The operator uses the data for backup, recovery, and related maintenance. The operator does not sell this data, use it for advertising, or use it to train AI models. The application transfers backup data to Google Drive for storage. Google's handling of data is governed by Google's applicable terms and privacy policies.

Retention and deletion

Backup retention varies by backup type. Automated retention rules remove older backups, and the operator can also delete backups from Google Drive. Revoking authorization does not itself delete previously uploaded backups.

Control over access

The operator can revoke Plex Backup's access through their Google Account's third-party connections settings. Revocation prevents continued authorized access and stops the application from refreshing its authorization. Backups already stored in Drive remain subject to retention or manual deletion.

This website and contact

These information pages contain no sign-in form, backup-upload feature, advertising, or application analytics. GitHub Pages provides the hosting and may process visitor information under GitHub's privacy statement.

For questions, open an issue in the public wess24m/plex-backup-site GitHub repository. Do not include passwords, authorization codes, tokens, backup contents, or other private information in an issue.
